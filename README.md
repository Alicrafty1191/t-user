<h1>t-user OSINT Tool</h1>
<p>
  t-user is an OSINT (Open Source Intelligence) tool designed to extract and display
  publicly available information about TikTok accounts. It can show details such as
  region, user app language, account creation date, and more.
</p>

<h1>How to Download?</h1>
<ul>
  <h2>For Linux (Android, Debian, Arch Linux...)</h2>
  <li>git clone https://github.com/Alicrafty1191/t-user.git</li>
  <li>cd t-user</li>
  <li>python3 tuser.py</li>
  <h3>OR</h3>
  <li>python3 t-user/tuser.py</li>
  <hr>

  <h2>For Windows</h2>
  <li>Install Python from <a href="https://python.org">Python.org</a></li>
  <li>Download tuser.py file to your computer</li>
  <li>Copy the file directory</li>
  <li>Open CMD and run <code>cd (file directory)</code></li>
  <li>Run <code>python3 tuser.py</code></li>
</ul>
